# Cleaner Pro v1.0 Free

Бесплатная утилита для Windows 10/11: показывает, что занимает место на диске,
и помогает удалить ненужное. Без рекламы, без сбора данных, без аккаунтов.

> **Статус: предварительная версия (pre-release).** Автоматические проверки
> пройдены (см. ниже), но программа проверялась на одном компьютере. Удаление
> необратимо — пользуйтесь осознанно и держите резервные копии важных данных.

## Что умеет

- **Диск** — переход по папкам любого диска (C:, D:, …), размер каждой папки,
  удаление выбранного файла или папки.
- **Программы** — установленные программы (из реестра) и папки игр/программ,
  отсортированные по размеру. Удаление — только **штатным деинсталлятором**
  программы; сама Cleaner Pro папки программ не удаляет.
- **Быстрая очистка** — фиксированный список категорий: временные файлы
  (%TEMP% и Windows\Temp), кэш загрузок Windows Update, кэш миниатюр, кэш
  шейдеров NVIDIA, кэш Chrome/Edge (профиль Default), Windows.old, Корзина.

## Важно: удаление без Корзины

Вкладки «Диск» и «Быстрая очистка» удаляют файлы **напрямую, минуя Корзину**.
Восстановить их средствами Windows нельзя. Перед удалением программа
показывает полный путь, а если путь проходит через ссылку — и фактическое
расположение.

**Windows.old** и **Корзина** по умолчанию не отмечены: их очистка необратима
(после удаления Windows.old нельзя откатиться на прежнюю версию Windows).

## Как запустить

- **Готовый .exe:** скачайте `CleanerPro.exe` со страницы
  [Releases](../../releases) и запустите. Python не нужен.
  Программа не подписана цифровой подписью, поэтому Windows SmartScreen может
  показать предупреждение. Запускайте файл, только если скачали его со
  страницы Releases этого репозитория, и при желании сверьте SHA-256 с
  `SHA256SUMS.txt` из релиза: `certutil -hashfile CleanerPro.exe SHA256`.
- **Из исходника:** установите Python 3.10+ и откройте `cleaner_pro.pyw`.
- **Собрать .exe самому:** `build.bat` (нужен Python; ставит PyInstaller,
  удаляет старый `dist\CleanerPro.exe`, при любой ошибке завершается с
  ненулевым кодом и сообщением BUILD FAILED, в конце печатает SHA-256).

Права администратора программе не нужны и сама она их не запрашивает. Если
деинсталлятор какой-то программы требует прав администратора, Windows
покажет обычный запрос UAC (как при запуске из Проводника).

## Как устроена защита

- **Нельзя удалить:** корень любого диска и сетевого ресурса (`\\сервер\папка`);
  папку Windows и ProgramData со всем содержимым — по имени на любом диске и по
  фактическому расположению (Windows на другом диске / с другим именем);
  контейнеры Program Files, Program Files (x86), Common Files, Users (и
  перенесённую папку профилей), профиль любого пользователя целиком, AppData
  текущего пользователя; любую папку, внутри которой лежит что-то из этого.
  Содержимое контейнеров (например, папку конкретной игры в Program Files)
  удалять можно.
- **Неподдерживаемые пути отклоняются:** относительные пути, `C:папка`, пустые
  значения, альтернативные потоки NTFS, пространства имён устройств
  (`\\?\Volume{…}`, `\\.\PhysicalDrive0`). Формы `\\?\C:\…`, `\\?\UNC\…`, `/`,
  `..`, регистр, точки и пробелы в конце имени приводятся к одному виду.
- **Ссылки** (symlink, junction и другие ссылки-«заменители имени») никогда
  не обходятся внутрь: удаляется только сама ссылка.
- **Подмена во время удаления (Windows):** строковый путь разбирается только
  один раз — при открытии выбранного объекта (без перехода по ссылке). Его
  реальное расположение проверяется по открытому дескриптору. Дальше
  содержимое перечисляется через дескриптор папки, а каждый вложенный объект
  открывается относительно дескриптора родителя (`NtCreateFile` с
  `RootDirectory`), а не по пути — поэтому переименование, подмена или
  перенацеливание junction в любом компоненте выше не может увести удаление в
  другое место. Удаление выполняется через тот же дескриптор. При
  подтверждении запоминается «отпечаток» объекта; если к моменту удаления по
  этому пути уже другой объект, удаление отменяется.
- **Быстрая очистка** работает только с путями из встроенного списка (точное
  совпадение). Реальное расположение папки категории проверяется по открытому
  дескриптору и обязано совпадать с путём из списка: если любой компонент пути
  (в том числе родительская папка) перенаправлен ссылкой, подключённым томом
  или SUBST, очистка этой категории отменяется. Список разрешённых путей не
  расширяется по фактическому расположению.
- **Деинсталляторы** запускаются без командной оболочки (`shell=False`), с
  явным путём к .exe. Повреждённые и неоднозначные команды не запускаются.
- Размер из кэша — только подпись в интерфейсе, а не разрешение на удаление.

## Проверки и их ограничения

Тесты лежат рядом с программой и работают только с временными данными
(реальные файлы, `C:\Windows\Temp` и Корзина не трогаются):

| Набор | Что проверяет |
|---|---|
| `test_security.py` | защита путей, allowlist быстрой очистки |
| `test_security_audit.py` | исправления аудита: формы путей, гонки с подменой папки на junction, junction в родителе категории очистки, перенацеливание родителя во время удаления, частичное удаление, разбор команд деинсталляции |
| `test_performance.py` | кэш, отмена и параллельный подсчёт размеров (открывает окна) |
| `test_regression.py` | регрессии логики и интерфейса (открывает окна) |
| `test_rc_fixes.py` | исправления RC (открывает окна) |
| `test_ui_polish.py`, `test_ui_icons.py` | масштаб, анимации, иконки (открывают окна; без дисплея GUI-часть пропускается) |

Ограничения, о которых нужно знать:

- Защита от подмены через дескрипторы работает только на Windows. Проверено на
  NTFS (Windows 11). FAT/exFAT, сетевые ресурсы и сторонние драйверы
  файловых систем отдельно не проверялись.
- Если при удалении подпапку успевают заменить ссылкой, удаляется ссылка, а
  не её цель — но то, что лежало в исходной подпапке, может остаться.
- Категория «Быстрой очистки», папка которой у вас перенесена ссылкой
  (например, перенаправлен AppData\Local), не очищается — это сознательный
  отказ, а не ошибка.
- Деинсталлятор — это чужая программа. Cleaner Pro проверяет только, что
  запускает именно указанный в реестре .exe; что делает деинсталлятор,
  программа не контролирует.
- Автоматическая проверка запуска EXE — только на одном компьютере, без
  различных версий Windows, DPI и антивирусов.
